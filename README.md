> A modern, responsive, seafood-focused food ordering web application that allows customers to seamlessly browse fresh menu items, manage their shopping cart, book tables, and place online orders.

---

## 🚀 Features

* **Seafood Restaurant Homepage:** An engaging and appetite-inducing landing page tailored for a premium seafood dining experience.
* **Interactive Food Menu:** Browse through categorized seafood dishes with descriptions and pricing.
* **Smart Shopping Cart:** Add items, adjust quantities, review order totals, and manage selections in real-time.
* **Table Booking Option:** Integrated reservation feature allowing customers to book a table directly on the platform.
* **Order Confirmation System:** Smooth checkout and confirmation workflow.

---

## 🗺️ Website Navigation & User Flow


1. **Visit the Homepage:** Explore highlighted dishes and restaurant information.
2. **Browse Menu:** Select from a variety of fresh seafood options.
3. **Manage Cart:** Add items, check item counts, and view the live bill summary.
4. **Checkout / Book:** Finalize your order or reserve a dining table.

---

## 🛠️ Built With

This project is built using core web technologies for fast performance and high responsiveness:

* **HTML5** – Semantic document structure
* **CSS3** – Modern styling, layouts, and responsive design (`style.css`)
* **JavaScript** – Dynamic UI rendering, cart management, and user interactions (`script.js`)
* **Python** – Utility scripts for asset and image handling (`copy_images.py`)
