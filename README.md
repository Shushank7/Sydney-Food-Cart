SydneyFoodCart
SydneyFoodCart is a seafood-focused food ordering website that allows customers to browse menu items, add products to a cart, and place orders online.

Features
Seafood restaurant homepage
Food menu browsing
Shopping cart functionality
Order confirmation system
Table booking option
Website Navigation
Home
Menu
Book Table
Cart
User Flow
Visit the homepage.
Browse available seafood dishes.
Add items to the cart.
Review the cart total.
Confirm the order.
